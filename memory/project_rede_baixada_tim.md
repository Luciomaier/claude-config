## O que falta para vender (bloqueador único)

Integração Asaas — fluxo:
1. Cliente escolhe plano → redireciona checkout Asaas
2. Webhook Asaas → confirma pagamento → ativa conta
3. Vencimento → Asaas cobra → inadimplente → suspende acesso

Usuário já consegue: cadastrar, login, painel, ver planos. Falta: pagar.
