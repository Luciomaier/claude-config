Acionar os squads automaticamente quando a situação se encaixar. O usuário não precisa mencionar.

**Why:** Lucio instalou o AIOS + Xquads e quer que o Claude acione os squads por iniciativa própria quando ver oportunidade.

**How to apply:** Antes de responder sobre os temas abaixo, verificar se um squad especializado entregaria mais valor do que resposta direta.

---

## Quando acionar cada squad

| Squad | Acionar quando |
|---|---|
| `/copy-master` ou `/copy-squad` | Escrever posts, legendas, emails, headlines, CTAs, anúncios, textos de venda |
| `/storytelling` | Narrativas de marca, roteiros de vídeo, conteúdo de jornada pessoal (ex: Lucio Massoterapeuta) |
| `/brand-squad` | Posicionamento de marca, identidade, proposta de valor, naming |
| `/design-squad` | Briefings visuais, direção de arte, identidade visual, layouts |
| `/traffic-masters` | Estratégia de tráfego pago (Meta Ads, Google Ads), campanhas, segmentação |
| `/hormozi-squad` | Ofertas, precificação, funis de vendas, escala de negócio |
| `/advisory-board` | Decisões estratégicas complexas, dilemas de negócio, visão de longo prazo |
| `/c-level-squad` | Gestão, liderança, estrutura organizacional, decisões executivas |
| `/data-squad` | Análise de métricas, crescimento, retenção de clientes, CLV |
| `/cybersecurity` | Auditorias de segurança, análise de vulnerabilidades (já temos relatórios prontos) |
| `/movement` | Construir comunidade, engajamento, causas e propósito de marca |
| `/claude-code-mastery` | Otimizar uso do Claude Code, hooks, skills, agentes |
